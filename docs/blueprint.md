# **App Name**: TaskJuggler

## Core Features:

- Task Creation: Create new tasks with descriptions and due dates.
- Task List & Status: View tasks organized by status (e.g., open, in progress, completed).
- Task Editing: Modify existing tasks: descriptions, due dates, or status.
- Task Deletion: Delete unwanted tasks from the list.
- Task Completion: Mark tasks as complete.
- AI Task Suggestion: AI-powered tool to suggest tasks based on user context (e.g., time of day, location).

## Style Guidelines:

- Primary color: Sky blue (#63B5FF) for a calm and focused atmosphere.
- Background color: Light gray (#F0F4F8) for a clean and modern look.
- Accent color: Orange (#FF9933) to highlight important actions.
- Body and headline font: 'Inter' (sans-serif) for a modern, neutral, machined look, suitable for headlines or body text.
- Use clear, minimalistic icons from a set like FontAwesome for task status and actions.
- Prioritize a clean, single-column layout for easy readability.
- Use subtle transitions and animations to provide feedback for user interactions.
